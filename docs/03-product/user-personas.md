# User Personas

The user types below are based only on the confirmed business and functional requirements from the discovery phase. They do not include additional user categories not supported by the requirements.

---

## Persona ID: P-001
### Name / Role: Casual Movie Viewer
### Status: Confirmed
### Description
A casual movie viewer is a user who wants to discover an interesting movie quickly without needing a complex entertainment platform. This user is looking for a simple, low-friction way to browse a catalog and decide what to watch later.

### Goals
- Find a movie that matches their immediate interest or mood
- Browse the available catalog with minimal effort
- Save titles they may want to watch later
- Avoid spending too much time searching or filtering

### Needs
- Easy access to a searchable catalog
- Clear visibility of available titles
- A simple way to save titles for future use
- Clear feedback when a search or watchlist action has no result

### Pain Points
- Too much complexity in entertainment platforms
- Difficulty deciding what to watch without a simple discovery flow
- Frustration when search results are unclear or empty
- Inability to keep track of previously identified movies

### Responsibilities
- Search for titles of interest
- Review results and decide which movies are relevant
- Save movies to a personal watchlist
- Remove movies if they are no longer relevant

### Technical proficiency
- Basic digital literacy
- Comfortable using a standard web app interface
- Prefers straightforward interactions with minimal learning curve

### Important tasks
- Search for a movie title or keyword
- Browse results
- Add a movie to the watchlist
- Review watchlist entries later
- Remove movies from the watchlist if needed

### Relevant system features
- Search and discovery
- Catalog browsing
- Watchlist add/remove
- Empty-state handling for no results
- Watchlist status indication

### Permissions / access level
- Standard end-user access only
- No administrative permissions
- No content management rights

## Persona ID: P-002
### Name / Role: Frequent Movie Watcher
### Status: Confirmed
### Description
A frequent movie watcher is a user who revisits the product regularly and maintains a shortlist of movies they want to watch. This user values repeat engagement and expects saved selections to remain available when they return.

### Goals
- Return to the product consistently
- Maintain a reliable watchlist over time
- Keep track of titles they want to watch later
- Continue discovering new films while managing saved ones

### Needs
- A watchlist that remains available across returns
- A predictable and dependable saved-item experience
- Clear differentiation between saved and unsaved titles
- A way to manage or remove outdated choices

### Pain Points
- Losing track of movies previously identified
- Unclear watchlist state
- Duplicate watchlist entries
- Returning to a product that does not preserve user decisions reliably

### Responsibilities
- Review the catalog repeatedly
- Save relevant titles to the watchlist
- Remove titles that are no longer desired
- Return to the product to continue discovery or revisit saved content

### Technical proficiency
- Comfortable with standard web interactions
- Likely familiar with list-based or bookmark-style systems
- Usually comfortable with minimal product training

### Important tasks
- Search for movies
- Save and revisit titles
- Manage watchlist content
- Return to review past selections
- Continue discovery after previous visits

### Relevant system features
- Search and filter behavior
- Watchlist creation and management
- Watchlist state preservation
- Duplicate prevention
- Clear saved/unsaved indicators

### Permissions / access level
- Standard end-user access only
- No administrative permissions
- No moderation or catalog editing rights

## Persona ID: P-003
### Name / Role: Genre-Focused Movie Explorer
### Status: Confirmed
### Description
A genre-focused movie explorer is a user who prefers to narrow the catalog based on interest or category. This user is motivated by specific preferences and wants discovery to be efficient and relevant.

### Goals
- Find movies in preferred categories
- Reduce the time spent reviewing unrelated titles
- Save movies that match genre preferences
- Continue using the system in a way that feels organized and relevant

### Needs
- Search and browsing that supports targeted discovery
- Clear results that match user intent
- Ability to save matching titles to a watchlist
- Clear empty-state responses when no relevant titles are found

### Pain Points
- Irrelevant or noisy search results
- Difficulty narrowing the catalog by preference
- Unclear no-result states that interrupt user flow
- Wasted time reviewing titles outside favored categories

### Responsibilities
- Search for movies relevant to preferred genres
- Review results for genre fit
- Save titles of interest to a watchlist
- Adjust search strategy when no titles match current criteria

### Technical proficiency
- Basic to intermediate digital confidence
- Comfortable with filtering or category selection
- Usually expects simple but structured navigation

### Important tasks
- Search or browse by title and category interest
- Review a reduced result set
- Save relevant titles
- Continue browsing after empty results
- Manage role-specific watchlist entries

### Relevant system features
- Search and discovery
- Result review
- Watchlist save/remove
- Empty-state handling
- Clear user guidance when no match is found

### Permissions / access level
- Standard end-user access only
- No administrative permissions
- No catalog management rights
